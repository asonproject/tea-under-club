# おさがりシェアリング機能 GAS セットアップ手順

## 前提
Asanaタスク①（3シート作成）・②（Apps Scriptの器作成）が完了していること。

**実際のSHARED_SECRET・ADMIN_EMAIL・デプロイURLの値は、このファイルには書かない。**
このリポジトリはGitHub Pagesで公開される（`asonproject/tea-under-club`）ため、READMEに書くとそのまま外部に漏れる。実際の値は`.gitignore`対象の `gas/.env.local` に控えること。

## 手順

1. `Code.gs` の中身を、②で作ったApps Scriptエディタの `コード.gs` に全て貼り付けて保存する。

2. 関数選択のプルダウンで `setupSheets` を選び、▶実行ボタンを押す（初回は権限承認のダイアログが出るので許可する）。3シート（公開商品／提供者情報／申込み）が自動作成され、既定の空シートは削除される。

3. スクリプトプロパティを2つ設定する。
   - Apps Scriptエディタ左メニュー「プロジェクトの設定」→「スクリプト プロパティ」→「プロパティを追加」
   - `SHARED_SECRET`：ランダムな文字列（`openssl rand -hex 16` 等で生成。値は`.env.local`に控える）
	   - 7978207a7230659c86e26e9d258f6d52
   - `ADMIN_EMAIL`：申込み通知を受け取りたいメールアドレス（値は`.env.local`に控える）

4. デプロイする。
   - 右上「デプロイ」→「新しいデプロイ」
   - 種類の選択：ウェブアプリ
   - 実行するユーザー：自分
   - アクセスできるユーザー：**全員**（Cloudflare Workersがサーバー間で呼び出すため。SHARED_SECRETが実質的な認証になる）
   - デプロイ後に発行される「ウェブアプリのURL」を`.env.local`に控える

5. コードやスクリプトプロパティを更新した場合、URLを維持したいなら「デプロイを管理」→鉛筆アイコン→バージョン：新バージョン→デプロイ、で更新する（「新しいデプロイ」を選ぶとURLが変わる）。

## 動作確認（デプロイ直後・任意）
ブラウザで以下にアクセスし、JSONが返ればOK（`YOUR_SECRET`は3で設定した値に置き換え）。

```
https://script.google.com/macros/s/xxxxx/exec?action=items&key=YOUR_SECRET
```

`公開商品`シートに1行もデータがない場合は `{"status":200,"items":[]}` が返る。まずは電動ベッドの行を1件手入力してから試すとわかりやすい。

## 注意
- `提供者情報`シートはこのAPIから一切参照していない（個人情報を公開APIに出さない設計）。申込みが来たら、`申込み`シートの商品IDを見て、担当者が`提供者情報`シートを手動で参照する運用。
- `SHARED_SECRET`は絶対にブラウザ側コード（HTML/JS）に書かない。Cloudflare Workersの環境変数にのみ置く。
